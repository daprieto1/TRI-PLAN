🕷 IRONMAN Scraper

Playwright-based browser automation that handles cookie consent, two-step login, and MUI DataGrid navigation on my.ironman.com.

  • Automated login with session reuse
  • Per-race JSON + screenshot export
  • Splits, rankings & points extraction
  • Rate-limited with configurable delay

🔌 MCP Integration

Model Context Protocol servers provide structured API access. Claude Code calls these directly to fetch and normalize athlete data.

  • Strava — 6 months of swim/bike/run activities with HR, pace, power
  • Oura — Sleep scores, readiness, HRV, resting HR
  • Cronometer — Daily macros, micros, hydration, body composition
  • Garmin* — Future: device-level training metrics

📈 Analysis Pipeline

Python scripts correlate training load with race performance to build projections. No ML — transparent statistical methods for small samples.

  • Weighted pace trends with outlier detection
  • Course-specific adjustments (elevation, heat)
  • 3-scenario projections with confidence ranges
  • Personalized nutrition plan from tracked intake
